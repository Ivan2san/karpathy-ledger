# raw/

Source cards, one per source. These are bibliographic entries with links and short paraphrased summaries, NOT reproductions of the source texts. Karpathy's essays, transcripts, and posts remain his copyright; follow the links to read the originals.

This folder is the immutable source-of-truth layer (per principle P50). The agent reads from it and never modifies the cards except to add new ones. Keeping raw immutable is the protection against the editorial trap (P75): you can always check the synthesis against what the source actually said.

If you want full local copies for your own offline reading and agent ingest, keep them in a gitignored subfolder so they are never published. The public repo carries cards and links only.
