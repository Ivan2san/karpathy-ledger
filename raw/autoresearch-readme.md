## Summary
A minimal repo where an agent runs ML experiments autonomously overnight: it edits one file, trains for a fixed five-minute budget, checks a scalar metric, keeps or reverts, and repeats. The human edits only the markdown brief. A working implementation of Software 3.0 and the verifiability thesis.

## Key claims
- Markdown is the programming language of Software 3.0; the human edits the brief, not the code (P23, P47).
- Constrain the surface, expand the autonomy; one scalar metric; fixed time budget; throughput math (P29 to P33).
- Remove yourself from the bottleneck (P62).
- "Disable all permissions" is part of the design (P42).
- The leverage is designing research orgs as code (P48).
